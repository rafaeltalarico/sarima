Projeto de extensão "Monitor Queimadas Cariri" da Universidade Federal do Cariri.

Alguns modelos preditivos foram testados para avaliar qual o melhor que se adaptava à solução proposta. Aqui, o modelo SARIMA (Seasonal AutoRegressive Integrated Moving Average), que é uma extensão do modelo ARIMA (AutoRegressive Integrated Moving Average) que incorpora a sazonalidade dos dados. Ele é amplamente utilizado para previsão de séries temporais que apresentam padrões sazonais.
